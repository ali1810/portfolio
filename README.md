# 🧬 Mushtaq Ali — Personal Portfolio Website

> **Live Site:** [ali1810.github.io/portfolio](https://ali1810.github.io/portfolio/)

A fully interactive, single-page personal portfolio showcasing my experience, skills, projects, and research as an AI Research Scientist at Karlsruhe Institute of Technology (KIT), Germany.

---

## 👤 About

I am an AI engineer with expertise in **machine learning, deep learning, NLP, cheminformatics, and spatial omics**. This portfolio was built to present my professional journey, research publications, and key projects in a clean and interactive format.

---

## 🚀 Features

- ⚡ Fully responsive single-page design
- 🎨 Dark theme with animated UI elements
- 🖱️ Custom cursor with hover interactions
- 📜 Scroll-reveal animations throughout
- 📁 All sections: Experience · Skills · Projects · Education · Publications · Achievements · Interests
- 🖼️ Embedded profile photo (no external dependencies)
- 🔗 Direct links to LinkedIn, GitHub, Google Scholar, ORCID, and ACS publication

---

## 🛠️ Built With

- HTML5
- CSS3 (animations, CSS variables, grid/flexbox)
- Vanilla JavaScript
- Google Fonts (Playfair Display, DM Mono, DM Sans)

No frameworks. No dependencies. Just one `index.html` file.
